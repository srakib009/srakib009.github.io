Backup — Data Copy করুন

নিচের বাটনে চাপুন — সব Leave, Overtime ও Employee data clipboard-এ copy হবে। Notepad বা যেকোনো জায়গায় paste করে সেভ করুন।

Restore — Data ফিরিয়ে আনুন

আগে copy করা backup text টি নিচে paste করুন।

সতর্কতা: Restore করলে বর্তমান সব data মুছে গিয়ে backup এর data আসবে। Restore করার আগে প্রয়োজনে আগে Backup Copy করে নিন।
